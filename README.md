# 🧮 Simple Calculator

A **responsive calculator** built with **HTML**, **CSS**, and **JavaScript**.  
This project allows users to perform basic arithmetic operations with a clean and minimal design.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🖥️ Responsive layout (works on desktop and mobile)
- 🎨 Simple and elegant UI
