# 🧮 Simple Calculator

A **responsive calculator** built with **HTML**, **CSS**, and **JavaScript**, assisted by **Trae AI** for development and improvements.  
This project allows users to perform basic arithmetic operations with a clean and minimal design.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🖥️ Responsive layout (works on desktop and mobile)
- 🎨 Simple and elegant UI
- 🤖 Developed with the help of **Trae AI**
